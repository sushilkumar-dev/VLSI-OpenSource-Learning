# 🔹 1.6 Waveform Analysis using GTKWave

GTKWave is a waveform viewer used to analyze the behavior of digital circuits after simulation. It reads the `.vcd` (Value Change Dump) file generated during simulation and displays how signals change over time. By opening the waveform using `gtkwave wave.vcd`, designers can load and observe signals such as inputs and outputs, and verify whether the circuit is functioning correctly according to its logic. The horizontal axis represents time, while the vertical axis shows signal values (0 or 1).

Using GTKWave, designers can zoom in and out to inspect transitions more closely, place markers to measure time delays, and change signal formats (binary, decimal, hexadecimal) for better understanding. It also allows grouping and organizing signals, making complex designs easier to analyze. Most importantly, GTKWave helps in debugging by comparing expected and actual outputs, ensuring the design is correct before proceeding to synthesis and physical design.
