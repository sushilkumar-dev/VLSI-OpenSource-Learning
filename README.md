# VLSI Open-Source Design Flow (ASIC Development)

## About
This repository demonstrates the complete ASIC design flow using open-source VLSI tools. It covers digital design from Verilog coding and simulation to synthesis, timing analysis, physical design, and final chip layout generation using the Sky130 PDK.

---

## Tools Used
- Icarus Verilog – Simulation  
- GTKWave – Waveform analysis  
- Yosys – Logic synthesis  
- OpenLane / OpenROAD – Physical design  
- Magic – Layout visualization  
- Sky130 PDK – Standard cell library  

---

## Learning Modules

### Chapter 1: Verilog & Simulation
- RTL design using Verilog  
- Testbench development  
- Waveform analysis

### Chapter 2: Synthesis
- RTL to gate-level conversion  
- Technology mapping using Sky130 `.lib`  
- Area and gate count analysis  

### Chapter 3: Timing Analysis
- Setup & hold timing  
- Slack and critical path  
- Static Timing Analysis (STA)  

### Chapter 4: Physical Design
- Floorplanning  
- Placement  
- Routing  
- Power distribution  

### Chapter 5: Signoff & Verification
- DRC (Design Rule Check)  
- LVS (Layout vs Schematic)  
- GDSII generation

**Note:** The same two designs (CMOS Inverter and AND Gate) are implemented across all chapters to demonstrate the complete ASIC design flow.
